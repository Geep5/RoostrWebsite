## Color Handling

All SVGs use `currentColor` for strokes and fills (primary content). Special cases:

- **Badge glyphs with masks**: Uses `<mask>` elements with white/black luminance for punch-out effects. Mask areas are black to cut out and white to show.
- **LayoutIcon plates**: Background fill uses `fill="white" fill-opacity="0.05"` (equivalent to `var(--hl-med)`).
- **Graph node fills**: Uses `currentColor` instead of CSS variables (original `var(--bg, #101216)` not portable to GPUI).

## GPUI Rendering

In GPUI, SVGs are rendered as monochrome masks and tinted by the element's text color. Ensure:
- No hard-coded colors except white/black in mask elements
- No CSS variables (`var(...)`)
- No `<style>` blocks
- ViewBox is width-independent (not tied to CSS px)
- No width/height attributes on root `<svg>` element
